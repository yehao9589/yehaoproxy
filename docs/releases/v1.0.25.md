## 更新内容

- 更新后台运营概览与客户账户概览；后台侧栏可直达待开通、待核验、即将到期和待回复事项。
- 统一按钮与状态标签样式，修正订单页按钮挤压、窄屏菜单和弹窗提示被遮挡等问题。
- 服务管理增加独立的到期状态与筛选；IP 和节点徽标固定为 34 × 34，长订单号省略后可悬停查看。
- 重排 VPS 面板备份工作区，分开查看备份文件、计划和任务；支持可选的 Cloudflare R2 异地加密副本。

## 验证

- 本地构建、类型检查与 164 项回归测试通过；VPS 和 R2 测试使用模拟服务。

## 部署说明

- 宝塔继续使用 `docker-compose.single.yml`（宝塔 MySQL + 单个 YehaoProxy 容器），保留 `data`、`uploads` 和 `backups` 持久化目录。
- 固定版本镜像：`ghcr.io/yehao9589/yehaoproxy:v1.0.25`。
- R2 异地备份默认关闭。启用前请配置私有存储桶、下载并单独保管解密密钥；详见 [R2 备份指引](https://github.com/yehao9589/yehaoproxy/blob/v1.0.25/docs/R2_BACKUPS.md)。本次发布不执行远端备份、升级或恢复。
