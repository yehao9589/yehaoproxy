## 更新内容

- 超期节点和代理 IP 不再从客户面板隐藏，继续保留在「已到期服务」。超过可续费期限后显示「已停止续费」，客户不能创建新的续费订单或发起支付。期限默认 30 天，沿用后台原有的期限设置。
- 「余额与流水」按全局默认每页条数分页，支持按北京时间筛选日期。不再只显示最近 100 条，历史流水、关联服务和备注仍可查看。
- 已退款、已取消和未付款的订单不再显示在节点服务列表，订单历史保留。
- 已开通的节点显示下次流量重置时间；逾期未执行显示「等待重置」，没有计划则显示「未安排」。
