## 更新内容

- 整合 VPS 运维中心：运行概览、面板与流量、服务器监控、面板备份和运维记录。
- 面板备份支持手动、批量和定时计划，以及保留策略、校验和下载；新计划默认关闭，沿用原有权限与凭据加密。
- 数据库和 Xray 配置下载文件使用“面板名称＋北京时间＋文件类型”命名，旧备份无需重新备份，内部文件路径不变。
- 新 IP 交付按同客户、同商品、同地区的上一名称自动递增；例如 `UK18-电脑` 建议 `UK19`，支持补零和手动自定义，连续交付自动更新建议。
- 同一客户的 WiFi 重名跨商品、跨地区检查，交付和编辑时提示关联 IP、订单；编辑排除当前 IP，重名不强制阻止保存。服务列表标记已有重名。
- 运维页面复用全局分页、刷新提示、开关和时间选择器，优化手机端与长弹窗操作区。

## 部署说明

- 宝塔仍使用 `docker-compose.single.yml`：宝塔 MySQL 加一个 YehaoProxy 容器，不需要新增公开端口。
- 保留现有 `data`、`uploads`、`backups` 持久化目录；VPS 备份位于 `backups/vps`。
- 固定版本镜像：`ghcr.io/yehao9589/yehaoproxy:v1.0.24`。
- 本次发布不会自动开启备份计划，也不会自动升级或恢复远端面板。
